Este proyecto consta de la secciones : Modelo donde esta los atributos de las clases post y user , Controladora donde estan los endpoints respectivos de cada uno como agregar eliminar y modificar entre otros y la seccion de las rutas donde estan las rutas respectivas de los endpoints

el sistema se basa en usarios que tiene posteos y estos usuarios se pueden agregar eliminar modificar etc , funciona igual para los posteos pero los posteos pueden recibir likes mediante los usuarios .

para correr el servidor se corre en la terminal el comando npm run dev

las dependecias usadas fueron nodemon , yarn , express , dotenv , cors y mongoose

osea se debe clonar el repo y ejecutar el npm install para descargar las dependencias
